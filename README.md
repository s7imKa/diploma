# Feature Matcher Studio (PyQt5 + OpenCV)

Desktop-додаток для пошуку однакових об'єктів на зображеннях і у відео. Побудовано на
ORB/AKAZE/SIFT, BFMatcher, RANSAC, з вкладеним інтерфейсом, таймлайном для відео, тепловими картами
та налаштуваннями.

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

## Основні можливості

- Алгоритми ознак: ORB, AKAZE, SIFT (якщо підтримується збіркою OpenCV).
- Matcher режими: KNN + Lowe ratio або BF crossCheck.
- Гомографія через RANSAC, підсвітка знайденого об'єкта, лінії відповідностей.
- Метрики схожості: inliers/min(kp), good/min(kp), reprojection error, stability, адаптивний поріг.
- Попередня обробка: Gaussian blur (опційно).
- Теплова карта щільності ключових точок.
- Відео: крок кадрів, адаптивний поріг, таймлайн, пауза/продовження, прогрес-бар.
- Темна тема, зум/панорамування, лог у док-панелі.

## UI/UX Redesign

**Інтерфейс переробений на 3 вкладки для максимальної зрозумілості:**

### 🖼️ Вкладка 1: Порівняння зображень

- **Ліва панель:** 1) Завантажити | 2) Аналіз | ⚙️ Налаштування
- **Центр:** Результат (лінії збігів, рамка об'єкта, інливал індикатор)
- **Низ:** Теплова карта + деталі (метрики, stability, адаптивний поріг)

### 📹 Вкладка 2: Пошук у відео

- **Ліва панель:** 1) Завантажити | 2) Управління | ⚙️ Параметри
- **Центр:** Прогрес, таймлайн кадрів, переглядач, деталі

### ⚙️ Вкладка 3: Навігація

- Описи, метрики, поради

## Структура

- `main.py` – вхідна точка.
- `ui/` – інтерфейс (вкладки, лог, таймлайн, зумований перегляд зображень).
    - `main_window.py` – головне вікно та логіка UI.
    - `image_viewer.py` – зум/панорамування зображень.
- `vision/` – логіка CV.
    - `feature_strategies.py` – стратегії ORB/AKAZE/SIFT (Strategy pattern).
    - `matcher.py` – детекція, матчинг, гомографія, метрики, heatmap.
    - `video_processor.py` – вибір кадрів, пауза/стоп, адаптивний поріг для відео.

## Обмеження

- SIFT потребує підтримки у вашій збірці OpenCV (у більшості `opencv-python` вже доступний).
- Проєкт не використовує deep learning; метод чутливий до великих деформацій/оклюзій.
- Адаптивний поріг базується на статистиці збігів та може вимагати ручного коригування для складних
  сцен.

## Приклади використання

1. Вкладка «Порівняння зображень»: завантажити два зображення, обрати алгоритм/режим у
   «Налаштування», натиснути «Порівняти», переглянути лінії збігів та рамку об'єкта; heatmap покаже
   щільність ключових точок.
2. Вкладка «Пошук у відео»: завантажити еталон (перше) зображення та відео, налаштувати
   `Кожні N кадрів` і поріг, запустити пошук. Таймлайн покаже кадри зі збігами, можна паузити та
   переходити між знайденими кадрами.

## Скриншоти

- Перегляд збігів із рамкою за гомографією.
- Теплова карта ключових точок.
- Таймлайн знайдених кадрів у відео та прогрес-бар.
