# UI/UX Guide для Feature Matcher Studio

## Дизайн-філософія

Інтерфейс побудований на **3 принципах:**

1. **Чіткість** — користувач одразу бачить, що завантажити і що натиснути
2. **Структурованість** — кожен логічний етап має окрему візуальну зону
3. **Ієрархія** — первинні дії більші, вторинні приховані в налаштуваннях

---

## Навігація по вкладках

### 🖼️ Вкладка 1: Порівняння зображень

**Ліва панель (Керування):**

```
┌─────────────────────────────────────────────────┐
│ 1️⃣ Завантажити зображення                      │
├─────────────────────────────────────────────────┤
│ [📂 Перше зображення]                           │
│ [📂 Друге зображення]                           │
├─────────────────────────────────────────────────┤
│ 2️⃣ Аналіз                                       │
├─────────────────────────────────────────────────┤
│ [▶️ Порівняти] (велика кнопка)                 │
│ [🔥 Heatmap]                                    │
├─────────────────────────────────────────────────┤
│ ⚙️ Налаштування (Image)                        │
├─────────────────────────────────────────────────┤
│ Алгоритм: [ORB ▼]                              │
│ Matcher: [KNN + Lowe ratio ▼]                  │
│ Lowe ratio: [0.75]                             │
│ [✓] Gaussian blur (kernel: 5)                  │
└─────────────────────────────────────────────────┘
```

**Центр (Результати):**

- **Великий переглядач** із лініями збігів (зелені = інлайєри, червоні = випадки)
- **Жовта рамка** навколо знайденого об'єкта за гомографією
- **Явний індикатор** схожості (зелено/червоно залежно від порога)

**Низ:**

- **Теплова карта** щільності ключових точок
- **Деталі:** алгоритм, good/min%, reproj error, stability, адаптивний поріг

### ⚙️ Вкладка 3: Навігація

Контекстна довідка про:

- Алгоритми ознак (ORB vs AKAZE vs SIFT)
- Режими matcher (KNN+ratio vs crossCheck)
- Метрики схожості та їх значення
- Поради для найкращих результатів

---

## Користувацькі сценарії

### Сценарій 1: Завантажити й порівняти два зображення

1. **Вкладка Image** → **📂 Перше зображення** → обрати файл еталона
2. **📂 Друге зображення** → обрати файл для порівняння
3. (Опційно) Налаштувати алгоритм/параметри у лівій панелі
4. **▶️ Порівняти**
5. Переглянути результат:
    - Зелені лінії = виявлені інлайєри
    - Жовта рамка = знайдений об'єкт
    - Зелений індикатор = схожість вище порога
6. **🔥 Heatmap** щоб побачити, де найбільше ключових точок

**Поради:**

- Яким більш чітке зображення, тим краще результат
- Якщо немає збігів, спробуйте AKAZE або SIFT замість ORB
- Gaussian blur допомагає при шумі на зображенні

---

### Сценарій 2: Знайти об'єкт у відео

1. **Вкладка Image** → завантажити еталонне зображення
2. **Вкладка Video** → **📽️ Завантажити відео**
3. (Опційно) Налаштувати:
    - **Крок кадрів:** Якщо відео 30 fps, крок 10 перевіряє кожні 0.33 сек
    - **Мін. схожість:** Нижче = більше кадрів, вище = тільки явні збіги
4. **▶️ Запустити пошук**
5. Переглядати результати в таймлайні
6. Клікнути на кадр → переглядач оновлюється з деталями
7. Використовувати **⏸ Пауза** для призупинення, **⏭ Крок** для навігації

**Поради:**

- Більший крок кадрів = швидше, але ризик пропустити момент
- Адаптивний поріг автоматично регулюється за статистикою
- Якщо знайдено 0 кадрів, спробуйте зменшити мін. схожість

## Налаштування

### Алгоритм ознак

| Алгоритм  | Швидкість | Точність   | Примітка                      |
| --------- | --------- | ---------- | ----------------------------- |
| **ORB**   | ⚡⚡⚡    | ⭐⭐       | Найшвидший, масові обчислення |
| **AKAZE** | ⚡⚡      | ⭐⭐⭐     | Компроміс, часто найкращий    |
| **SIFT**  | ⚡        | ⭐⭐⭐⭐⭐ | Найточніший, але повільний    |

**Вибір:** Почніть з AKAZE, якщо результати погані — спробуйте SIFT

### Режим Matcher

- **KNN + Lowe ratio:** Два найкращі кандидати + фільтрація (за замовчуванням)
- **BF crossCheck:** Взаємна відповідність (строгіше, менше помилок)

### Lowe ratio

- **0.5:** Дуже строгий, мало помилок, але можна пропустити збіги
- **0.75:** Збалансований (за замовчуванням)
- **1.0:** Занадто м'який, багато хибних позитивів

### Gaussian blur

- **Увімкнути:** Допомагає при шумі на зображенні
- **Kernel size:** 3–5 (малий), 7–11 (середній), 13–21 (великий)

## Метрики розуміння

| Метрика          | Значення                      | Норма                     |
| ---------------- | ----------------------------- | ------------------------- |
| **Similarity**   | inliers / min(kp)             | > 20% = добра             |
| **Good matches** | good_count / min(kp)          | > 30% = хороша            |
| **Reproj error** | Середня помилка переспроєкції | < 5 = добра               |
| **Stability**    | 1 / (1 + error)               | > 0.7 = стійка            |
| **Adaptive**     | Динамічний поріг              | Змінюється за статистикою |

## Лог-панель (внизу вікна)

Містить повідомлення про дії та результати:

- **✓ Зелене** = успіх (знайдено збіги)
- **⚠ Жовте** = попередження (частково, пауза)
- **✗ Червоне** = помилка (не завантажено, не знайдено)

Приклади:

```
✓ Перше зображення завантажено: photo1.jpg
⏱ Запуск пошуку: крок=10, поріг=20%
✓ Кадр #150: 45.2% (адаптивний 35.1%)
✓ Пошук завершено. Знайдено 12 кадрів
```

---

## Статус-бар (праворуч внизу)

- **✓ Готово** (зелено) = не обробляється
- **Обробка...** (жовто) = наразі вибір аналізується
- **✗ Помилка** (червоно) = щось пішло не так

---

## Поради для отримання найкращих результатів

1. **Якість зображення**
    - Чіткі, добре освітлені зображення
    - Від 100×100 пікселів мінімум
    - Не надто розмиті або зашумлені

2. **Вибір алгоритму**
    - Спочатку AKAZE (найбільш універсальний)
    - Якщо результати погані, спробуйте SIFT
    - ORB лише для дуже простих сцен

3. **Параметр Lowe ratio**
    - Малого (0.5–0.6) — більш надійні збіги
    - Збільшуйте (до 0.8–0.9), якщо результатів замало

4. **Gaussian blur**
    - Ввімкніть, якщо на зображенні видно шум
    - Kernel 5–7 найчастіше оптимальний

5. **Відео параметри**
    - **Крок кадрів:** 5–10 для повільних рухів, 15–20 для швидких
    - **Мін. схожість:** 15–25 — компромісний діапазон

---

## Типові проблеми

| Проблема                         | Рішення                              |
| -------------------------------- | ------------------------------------ |
| Немає збігів                     | Спробуйте SIFT, зменшіть Lowe ratio  |
| Занадто помилок                  | Збільшіть Lowe ratio, увімкніть blur |
| Повільна обробка відео           | Збільшіть крок кадрів                |
| Пропускаєте шукаємий об'єкт      | Зменшіть крок кадрів                 |
| Адаптивний поріг занадто низький | Перевизначте мін. схожість вручну    |

---

## Клавіатура та мишка

- **Наведіть на кнопку** — подсвітка параметра (tooltip)
- **Колесо миші в переглядачі** — zoom in/out
- **Ліва кнопка миші в переглядачі** — pan (перетягування)
- **Клік на кадр у таймлайні** — прегляд деталей
